# Train Ticket Booking System
A console-based Train Ticket Booking System developed using Core Java, JDBC, MySQL, and Maven.

## Features
- Add Train
- View Train Details
- Search Train
- Book Ticket
- View Booking
- Cancel Booking
- Update Train Fare
- Delete Train
- Database Connectivity using JDBC

## Technologies Used
- Java
- JDBC
- MySQL
- Maven

## Project Structure
- Entity Layer
- DAO Layer
- Service Layer
- Database Layer

## Project Description
- This project is designed to manage train and ticket booking operations. Users can add trains, search trains, book tickets, view bookings, cancel bookings, update train fares, and delete train records. JDBC is used to connect with the MySQL database, while Maven is used for dependency management and project configuration.

## Learning Outcomes
- Core Java Programming
- JDBC Connectivity
- MySQL Database Operations
- CRUD Operations
- Maven Project Management
- Layered Architecture
